> **最短路径**：四大来源就能覆盖绝大多数公开口令。要哪一类直接下哪一类，别整个仓库拖。
>
> | 想要什么 | 去哪拿 |
> | --- | --- |
> | 通用弱口令榜、各国语言榜、泄露库大合集 | [SecLists](https://github.com/danielmiessler/SecLists) → `Passwords/` |
> | 单文件最大、命中率最高的人类口令榜 | [CrackStation human-only](https://crackstation.net/files/crackstation-human-only.txt.gz)（683 MB / 6394 万行） |
> | 中文弱口令、设备默认口令、webshell / 爆破字典 | [Blasting_dictionary](https://github.com/rootphantomer/Blasting_dictionary) + [fuzzDicts](https://github.com/TheKingOfDuck/fuzzDicts) |
> | 规则文件（把字典放大几十倍） | hashcat 自带 `rules/`，或 SecLists 的 `Passwords/` 同级目录 |
>
> 下面还有一份可直接跑的批量下载脚本，以及一条比「下得更多」重要得多的结论。

## 先算清楚要多少

本机一份完整字典集的实测规模：

| 目录 | 文件数 | 大小 | 内容 / 来源 |
| --- | ---: | ---: | --- |
| `chinese/` | 25 | 11.7 MB | Blasting_dictionary + fuzzDicts（中文 / 弱口令 / 设备默认口令） |
| `common/` | 28 | 19.7 MB | SecLists `Passwords/Common-Credentials`（Pwdb-Public、NCSC、Xato、weakpass probable-v2、DarkWeb2017 等） |
| `keyboard/` | 2 | 4.5 MB | SecLists `Passwords/Keyboard-Walks`（键盘走位） |
| `language/` | 19 | 47.3 MB | SecLists `Passwords/Common-Credentials/Language-Specific`（各国语言，含中文榜） |
| `leaked/` | 25 | 261.9 MB | SecLists `Passwords/Leaked-Databases`（rockyou、phpbb、myspace、Ashley-Madison、000webhost 等） |
| `misc/` | 10 | 984.7 MB | SecLists `Passwords` 杂项 + CrackStation human-only |
| **合计** | **109** | **1.3 GB** | **约 1.015 亿行明文** |

其中占绝对大头的是两个文件：

| 文件 | 大小 | 行数 |
| --- | ---: | ---: |
| `crackstation-human-only.txt` | 683.3 MB | 63,941,069 |
| `rockyou.txt` | 133.4 MB | 14,344,391 |

**1.3 GB 里 800 MB 是这两个。** 如果只想要「性价比最高的 200 MB」，就下 `common/` + `chinese/` + `rockyou`，命中率不会有可见的下降。

## 来源清单

| 来源 | 地址 | 拿什么 |
| --- | --- | --- |
| **SecLists** | <https://github.com/danielmiessler/SecLists> | 全集。`Passwords/` 下分 `Common-Credentials`、`Leaked-Databases`、`Keyboard-Walks`、`Language-Specific` 等子目录 |
| **CrackStation** | <https://crackstation.net/files/crackstation-human-only.txt.gz> | 人类口令榜，6394 万行，单文件天花板。hashcat 可直接读 `.gz` |
| **Blasting_dictionary** | <https://github.com/rootphantomer/Blasting_dictionary> | 中文场景：常用密码、渗透字典、3389 爆破、装机密码、webshell 口令、路由器默认口令 |
| **fuzzDicts** | <https://github.com/TheKingOfDuck/fuzzDicts> | 中文场景补充：`passwordDict/` 下有 top500~top19576、生日、WiFi 默认口令、某集团下发弱口令 |
| **openwall wordlists** | <https://www.openwall.com/wordlists/> | 老牌整理，John 官方推荐 |
| **weakpass** | <https://weakpass.com> | 按泄露批次整理的合集，体量极大 |

::: tip 用 raw 直链，别 clone
这些仓库动辄几百 MB 到几 GB 历史。要单个文件就走 `https://raw.githubusercontent.com/<owner>/<repo>/master/<path>`，省掉 `.git` 和无关目录。
:::

## 批量下载脚本（可直接跑）

思路：把「输出路径 + 远端 URL」写成一张清单，逐条下载；**已存在且非空的文件跳过**，失败重试，最后自动解开 `.tar.gz`。这样中断了再跑一遍就是续传。

```powershell
$ErrorActionPreference = 'Continue'

# 直连 GitHub 慢的话填本地代理，比如 http://127.0.0.1:<端口>；不需要就留空串
$Proxy = ''
$WL    = Join-Path (Get-Location) 'Wordlist'
$Raw   = 'https://raw.githubusercontent.com'

$SL   = "$Raw/danielmiessler/SecLists/master/Passwords"
$SLCC = "$SL/Common-Credentials"
$SLLD = "$SL/Leaked-Databases"
$SLLS = "$SLCC/Language-Specific"

# ---- 清单："输出相对路径|URL" ----
$m = @()

# SecLists：通用弱口令榜（性价比最高的一批，先下这些）
$common = @(
  '10k-most-common.txt', '100k-most-used-passwords-NCSC.txt', '1900-2020.txt',
  '500-worst-passwords.txt',
  'Pwdb_top-1000.txt', 'Pwdb_top-10000.txt', 'Pwdb_top-100000.txt', 'Pwdb_top-1000000.txt',
  'darkweb2017_top-10000.txt', 'probable-v2_top-12000.txt',
  'xato-net-10-million-passwords-100000.txt', 'xato-net-10-million-passwords-1000000.txt',
  'top-20-common-SSH-passwords.txt', 'medical-devices.txt'
)
foreach ($f in $common) { $m += "common/$f|$SLCC/$f" }

# SecLists：泄露库（rockyou 是必下项）
$leaked = @('rockyou.txt.tar.gz', '000webhost.txt', 'Ashley-Madison.txt', 'phpbb.txt', 'myspace.txt')
foreach ($f in $leaked) { $m += "leaked/$f|$SLLD/$f" }

# SecLists：语言榜（中文榜在这里）
$lang = @(
  'Chinese-common-password-list-top-10000.txt',
  'Chinese-common-password-list-top-100000.txt',
  'Chinese-common-password-list.txt',
  'Cantonese_Pwdb_common-password-list-top-150.txt'
)
foreach ($f in $lang) { $m += "language/$f|$SLLS/$f" }

# SecLists：键盘走位 + 杂项
$m += "keyboard/walk-the-line.txt|$SL/Keyboard-Walks/walk-the-line.txt"
$m += "misc/openwall.net-all.txt|$SL/openwall.net-all.txt"
$m += "misc/days.txt|$SL/days.txt"
$m += "misc/months.txt|$SL/months.txt"

# 中文社区字典（注意：这些文件名是中文，URL 必须做转义）
$BD = "$Raw/rootphantomer/Blasting_dictionary/master"
foreach ($f in @('常用密码.txt','渗透字典.txt','top100password.txt','top10W.txt','NT密码.txt')) {
  $m += "chinese/blasting/$f|$BD/$([uri]::EscapeDataString($f))"
}
$FD = "$Raw/TheKingOfDuck/fuzzDicts/master/passwordDict"
foreach ($f in @('top1000.txt','top6000.txt','top19576.txt','birth.txt','wifi_top2000_passwd.txt')) {
  $m += "chinese/fuzzdicts/$f|$FD/$([uri]::EscapeDataString($f))"
}

# CrackStation（单独放，体量最大）
$m += "misc/crackstation-human-only.txt.gz|https://crackstation.net/files/crackstation-human-only.txt.gz"

# ---- 执行 ----
$fail = @()
foreach ($line in $m) {
  $rel, $url = $line -split '\|', 2
  $out = Join-Path $WL ($rel -replace '/', '\')

  if ((Test-Path $out) -and (Get-Item $out).Length -gt 0) { Write-Output "SKIP $rel"; continue }

  New-Item -ItemType Directory -Force -Path (Split-Path $out) | Out-Null
  $curlArgs = @('-sS','-L','--retry','3','--retry-delay','2','--retry-all-errors','--max-time','3600','-o',$out)
  if ($Proxy) { $curlArgs += @('-x', $Proxy) }
  & curl.exe @curlArgs $url 2>&1 | Out-Null

  if ((Test-Path $out) -and (Get-Item $out).Length -gt 0) {
    Write-Output ("OK   {0} ({1} bytes)" -f $rel, (Get-Item $out).Length)
  } else {
    Write-Output "FAIL $rel  $url"; $fail += $rel
    if (Test-Path $out) { Remove-Item $out -Force }
  }
}
Write-Output ("failed: " + $(if ($fail.Count) { $fail -join ', ' } else { 'none' }))

# ---- 解开 .tar.gz（rockyou 是 tar.gz 打包的）----
Get-ChildItem $WL -Recurse -Filter '*.tar.gz' | ForEach-Object {
  Write-Output "extracting $($_.FullName)"
  & tar.exe -xzf $_.FullName -C $_.DirectoryName 2>&1 | Out-Null
}
Write-Output 'DONE'
```

几个实际会踩的点：

- **中文文件名必须转义。** `raw.githubusercontent.com` 对路径里的非 ASCII 字符不认，要用 `[uri]::EscapeDataString()` 转成百分号编码。
- **`-x <代理>` 是给 `curl` 的，不是给 PowerShell 的。** 只设 `$env:HTTP_PROXY` 对 `curl.exe` 不一定生效。
- **`.tar.gz` 和 `.gz` 不一样。** `rockyou.txt.tar.gz` 要先解包；而 `crackstation-human-only.txt.gz` 是单文件压缩，**hashcat 能直接读 `.gz`，不用解**（解开会白占一倍磁盘）。
- **`--retry-all-errors` 很有用**，大文件传到一半断的情况不少。

## 下载完之后

字典是给 hashcat 用的，用法和取舍见 [压缩包口令破解的优先级](./压缩包破解优先级.md)。这里只说三件最容易忘的事：

1. **先跑 top-1000，再跑 top-10 万，最后才上 rockyou。** 顺序反了就是拿 1 小时换 1 秒。
2. **规则文件比字典更能放大命中率。** `best64` 只花几秒就能把 10 万字典变成几百万候选，性价比远高于再下 500 MB。
3. **`.gz` 别解压**，hashcat 原生支持。

## 最重要的一条：字典覆盖 ≠ 覆盖到位

这是实测里最反直觉、也最值钱的发现。

拿一份 **1.3 GB / 1.015 亿行**的全量字典做精确检索，三个已经确知的口令**一条都没命中**：

| 口令类型 | 在 1.015 亿行里的命中 |
| --- | --- |
| 与本人昵称相关的 7 位小写 | **0 条**（以昵称前几字母开头的条目只匹配到无关的词） |
| 资源站域名风格（`站点.com`） | **0 条**（库里只有形近但不同的串） |
| 4 个汉字的中文短语 | **0 条**（连其中任意一个词单独查都是 0 条） |

原因很明确：

- **SecLists 的中文榜基本是「数字 + 拼音」**，它不是中文口语语料。
- **公开泄露库以欧美为主**，没有中文网络流行语，也没有「拼音昵称怎么写」这种个人化变体。
- **「站点域名当密码」这个在中国资源站上极其常见的习惯，公开库里几乎没有对应榜。**

所以正确的动作不是「再下一个更大的字典」，而是**定向生成**：

- **拼音类**：全拼 + 首字母缩写 + 常见昵称写法
- **域名类**：拿 top-10 万字典批量加 `.com` / `.cn` / `.net` 后缀（一条规则就够，不需要新字典）
- **中文流行语 / ACG 词表**：自己整理，公开库里没有
- **已知信息派生**：姓名、生日、手机号后几位、项目名、年份

::: warning 一句话总结
**下字典解决的是 L0–L2，L3 只能靠已知信息生成。** 把预算继续投在「更大的字典」上，收益会迅速趋近于零。
:::
